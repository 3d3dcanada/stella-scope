WHAT WAS DONE TO IT
The STEP assembly was converted into a triangle mesh in glTF 2.0 binary form (a .glb file, then gzipped) so that Stella Scope can draw the printer on screen. The parts were named and grouped so that the axes can move with the printer, and given the colours of the real machine (the STEP carries none). Nothing was added to Prusa's geometry. The CAD is the CORE One as Prusa released it in December 2025; the changes of the CORE One+ (Gen 2), such as the belts, the nozzle wiper and the top panel, are small parts and are not drawn. The conversion is tools/printer-cad/step_to_glb.py in the Stella Scope source, with tools/printer-cad/prusa-core-one/groups.json; anyone can repeat it from Prusa's STEP file and gets the same bytes.
