Stella Scope itself is not under the GPL and a model is a separate file beside it.

WHAT WAS DONE TO IT
The STEP assembly was converted into a triangle mesh in glTF 2.0 binary form (a .glb file, then gzipped) so that Stella Scope can draw the printer on screen. The STEP is written with the vertical axis up and the display at the back; the conversion turns it upright with the display at the front. The parts were named and grouped so that the axes can move with the printer, and the printed parts were given the orange of the real machine (the STEP carries no colours). Nothing was added to the geometry. The conversion is tools/printer-cad/step_to_glb.py in the Stella Scope source, with tools/printer-cad/prusa-mini/groups.json; anyone can repeat it from the STEP file and gets the same bytes.
